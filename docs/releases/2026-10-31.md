# Native release — 2026-10-31

Both platforms use source `0f1a68aa75c47a045f5cead348dde98bed1d2267`, runtime
`7`, the `production` update channel and `https://eng.xyznot.com`.

| Platform | Version | Distribution |
| --- | --- | --- |
| iOS | 0.1.0 (32) | TestFlight, Internal group; processing VALID, IN_BETA_TESTING |
| Android | 0.1.0 (11) | [Signed APK](https://github.com/nomoat/tmux-mobile-mobile/releases/tag/android-v0.1.0-11) |

The installed app name is **T-MAX**. App Store Connect and TestFlight use
**T-MAX Terminal** because Apple reports that the shorter name is already in use
by another account. The package and bundle ID remain `ai.impo.tmuxmobile`.

This release includes the accumulated speech provider selection, dictation,
Vision Pro input controls, session picker, terminal sharing and text-selection
changes. The server and Connector fixes for Claude worktree histories were
released separately.
